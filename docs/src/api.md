# API reference

The Rust API reference is built by rustdoc from the engine's doc comments:

- [`walkit`](api/walkit/index.html): the engine.

Start at [`SkinRuntime`](api/walkit/runtime/struct.SkinRuntime.html), the
[`SkinHost`](api/walkit/host/trait.SkinHost.html) and
[`Player`](api/walkit/player/trait.Player.html) traits, and
[`DrawCmd`](api/walkit/draw/enum.DrawCmd.html).

The web package's types are in
[`web/embed.d.ts`](https://github.com/mattijsf/walkit/blob/main/web/embed.d.ts).
